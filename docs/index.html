Cómo funciona esta demo

01

El formulario envía un POST directo al webhook de producción del flujo de n8n — el mismo que usaría un formulario real de la web.

02

n8n manda el mensaje a un modelo de IA (Llama 3.3 vía Groq), que devuelve presupuesto, urgencia, sector y un resumen ejecutivo en JSON estructurado.

03

Ese resultado es el mismo que se usaría para crear la oportunidad en el CRM (Odoo) con etiquetas automáticas y prioridad asignada.

04

Por seguridad, esta demo pública limita los envíos por sesión. Es solo para mostrar el flujo — no reemplaza el formulario de producción real.
